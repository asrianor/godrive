Bimbingan Teknis Pengembangan Karir PTK Berbasis SKP dan Kinerja Digital (E-kinerja)

Optimalisasi Google Drive sebagai Media Penyimpanan Bukti Dukung untuk Efisiensi Jabatan.

Gunakan tombol di bawah atau tombol panah keyboard untuk menavigasi materi.

Poin Pembahasan

1. Google Drive
Manajemen folder dan upload dokumen bukti dukung.
2. Hak Akses
Pengaturan privasi dan berbagi link untuk verifikator.
3. Otomatisasi
Penggunaan shortcut dan script untuk efisiensi kerja.

2. Memulai

Buka drive.google.com
Login dengan akun Google (tidak harus akun resmi).
Pastikan akun dapat diakses dengan mudah.
Gunakan akun yang paling sering Anda gunakan agar lebih praktis.

3. Arsitektur Folder

Klik + Baru > Folder baru
Beri nama: Administrasi 2026
Administrasi 2026
 ├── Surat Kedinasan
 │     ├── Januari
 │     └── Februari
 ├── SPJK
 │     └── SPJK-01
 └── SPP
       └── SPP-Kegiatan

4. Upload File

Upload dokumen dalam format PDF.
Drag & drop file langsung ke folder.
Pastikan nama file deskriptif (contoh: SPJK-Mei.pdf).

5. Bagikan Link

Secara Default: Hak akses dibatasi (Privat).
Klik kanan > Bagikan (Share)
Ubah ke "Siapa saja dengan link"
Pastikan Anda menyalin link setelah mengatur hak akses di slide berikutnya.

6. Jenis Hak Akses

Viewer (Pelihat)
Hanya bisa melihat dan mendownload. Paling aman untuk verifikator.
Commenter (Pengomentar)
Bisa melihat dan memberikan catatan/komentar pada dokumen.
Editor (Pengedit)
Bisa mengubah, menghapus, dan mengatur ulang file/folder.
Gunakan Viewer untuk link bukti dukung agar data tidak sengaja terhapus.

7. Shortcuts

Alt + C , F
Membuat Folder Baru
Alt + C , U
Upload File
Alt + C , I
Upload Folder

8. Otomasi 1 (Nama Statis)

Gunakan Google Apps Script untuk membuat folder dengan nama tetap secara otomatis.

function buatFolder() {
  var folder = DriveApp.createFolder("Bukti-2026");
  folder.setSharing(
    DriveApp.Access.ANYONE_WITH_LINK,
    DriveApp.Permission.VIEW
  );
  Logger.log(folder.getUrl());
}

9. Otomasi 2 (Nama Kustom)

User dapat memasukkan nama folder sendiri melalui kotak dialog.

function buatFolderCustom() {
  var nama = Browser.inputBox("Masukkan nama folder:");
  if (nama == "cancel") return;

  var folder = DriveApp.createFolder(nama);
  folder.setSharing(
      DriveApp.Access.ANYONE_WITH_LINK,
      DriveApp.Permission.VIEW
  );

  Browser.msgBox("Link: " + folder.getUrl());
}
