Penyimpanan Bukti Dukung Administrasi

Panduan Modern Menggunakan Google Drive untuk Efisiensi Pelaporan.

Gunakan tombol di bawah atau tombol panah keyboard untuk menavigasi materi.

Poin Pembahasan

1. Google Drive
Manajemen folder dan upload dokumen bukti dukung.
2. Hak Akses
Pengaturan privasi dan berbagi link untuk verifikator.
3. Otomatisasi
Penggunaan shortcut dan script untuk efisiensi kerja.

2. Memulai

Buka drive.google.com
Login dengan akun resmi instansi.
Keamanan data adalah prioritas utama.
Akun instansi biasanya memiliki kuota penyimpanan yang lebih besar.

3. Arsitektur Folder

Klik + Baru > Folder baru
Beri nama: Administrasi 2026
Administrasi 2026
 ├── Surat Kedinasan
 │     ├── Januari
 │     └── Februari
 ├── SPJK
 │     └── SPJK-01
 └── SPP
       └── SPP-Kegiatan

4. Upload File

Upload dokumen dalam format PDF.
Drag & drop file langsung ke folder.
Pastikan nama file deskriptif (contoh: SPJK-Mei.pdf).

5. Bagikan Link

Klik kanan > Bagikan (Share)
Ubah ke "Siapa saja dengan link"
Pilih peran: Viewer (Pelihat)
Klik "Salin link" untuk digunakan pada laporan.

6. Shortcuts

Alt + C , F
Membuat Folder Baru
Alt + C , U
Upload File
Alt + C , I
Upload Folder

7. Otomasi API

Gunakan Google Apps Script untuk otomatisasi.

function buatFolder() {
  var folder = DriveApp.createFolder("Bukti-2026");
  folder.setSharing(
    DriveApp.Access.ANYONE_WITH_LINK,
    DriveApp.Permission.VIEW
  );
  Logger.log(folder.getUrl());
}

Selesai!
