Google Drive Tutorial

Panduan lengkap menggunakan Google Drive sebagai media penyimpanan bukti dukung administrasi yang efektif dan terorganisir.

Google Drive adalah platform penyimpanan awan (cloud storage) yang sangat efektif untuk mengelola dokumen bukti dukung seperti Surat Kedinasan, SPJK, SPP, laporan kegiatan, dan dokumen penting lainnya. Dengan fitur kolaborasi dan berbagi link, dokumen Anda akan lebih mudah diakses dan dilaporkan.

1. Memulai Google Drive

  1. Kunjungi drive.google.com
  2. Login menggunakan akun Google atau akun instansi Anda.
  3. Jelajahi dasbor utama untuk melihat ruang penyimpanan Anda.
Tips Pro: Gunakan akun resmi instansi agar dokumen tetap aman dan terorganisir dalam satu domain.

2. Arsitektur Folder

Memasukkan file tanpa struktur akan menyulitkan pencarian di masa depan. Gunakan tombol + Baru untuk mulai merapikan dokumen.

  1. Klik tombol + Baru (New) di pojok kiri atas.
  2. Pilih Folder baru.
  3. Gunakan penamaan yang konsisten (misal: Administrasi 2026).

Struktur folder yang direkomendasikan:

Administrasi 2026
 ├── Surat Kedinasan
 │     ├── Januari
 │     └── Februari
 ├── SPJK
 │     ├── SPJK-01
 │     └── SPJK-02
 └── SPP
       ├── SPP-Gaji
       └── SPP-Kegiatan

3. Manajemen File Dokumen

Setelah folder siap, Anda bisa mengupload dokumen bukti dukung dalam format PDF atau gambar.

  • Surat-Kedinasan.pdf
  • SPJK-Kegiatan-Maret.pdf
  • SPP-Belanja-Alat.pdf

Cara Upload: Cukup klik + Baru > Upload file, atau seret langsung (drag & drop) file dari komputer Anda ke dalam jendela browser.

4. Berbagi & Hak Akses

Ini adalah bagian krusial agar link Anda bisa dibuka oleh verifikator laporan.

  1. Klik kanan pada file atau folder yang ingin dibagikan.
  2. Pilih menu Bagikan (Share).
  3. Ubah akses umum menjadi "Siapa saja yang memiliki link".
  4. Pilih peran:
    • Viewer: Hanya bisa melihat (Direkomendasikan).
    • Commenter: Bisa memberi catatan.
    • Editor: Bisa mengedit/menghapus.
  5. Klik Salin link dan tempelkan ke laporan Anda.

5. Efisiensi Kerja (Shortcuts)

Shortcut Fungsi

Alt + C + I Membuat Folder Baru

6. Otomasi dengan Google Apps Script

Gunakan script ini untuk membuat folder secara massal atau otomatis dengan hak akses yang sudah tersetting.

Fungsi Dasar Buat Folder:

function buatFolder() {
  var namaFolder = "Bukti Dukung 2026";
  var folder = DriveApp.createFolder(namaFolder);
  
  folder.setSharing(
      DriveApp.Access.ANYONE_WITH_LINK,
      DriveApp.Permission.VIEW
  );

  Logger.log("Link Folder: " + folder.getUrl());
}

Fungsi Custom (User Input):

function buatFolderCustom() {
  var nama = Browser.inputBox("Masukkan nama folder:");
  if (nama == "cancel") return;

  var folder = DriveApp.createFolder(nama);
  folder.setSharing(
      DriveApp.Access.ANYONE_WITH_LINK,
      DriveApp.Permission.VIEW
  );

  Browser.msgBox("Sukses! Link: " + folder.getUrl());
}
